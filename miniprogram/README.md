# 希美 · XM 微信小程序初版

原生微信小程序源码，包含首页、衣橱分类、服饰详情、穿搭图集、店铺相册五个页面。采用网站同款奶油白、深棕与实拍照片，支持原生相册浏览、分享给朋友、朋友圈分享配置。单件服饰分享保留商品 ID 与所选颜色。

## 当前状态

- 源码和界面预览已准备。
- 尚未注册小程序账号，`project.config.json` 使用 `touristappid` 作为开发占位。
- 浏览器预览模拟微信接口，不能真的把小程序发送到微信。
- 尚未上传、提交审核或正式发布；没有生成可用的小程序码。
- 功能测试使用模拟 `wx` 接口；仍需在微信开发者工具和真实手机上验收。

## 查看界面

在仓库根目录运行：

```sh
npm run mini:preview
```

打开 http://127.0.0.1:4174/mini-preview/ 。预览直接读取 WXML、WXSS、Page 代码和同一份数据，但没有实现完整微信运行时。与实际微信布局或组件行为可能存在差异。

## 导入微信开发者工具

1. 下载官方微信开发者工具。
2. 导入本目录 `miniprogram/`。
3. 尚无账号时，可尝试开发者工具提供的测试号或游客模式。工具版本及权限决定哪些功能可测试，不承诺游客模式支持真机预览和原生分享。
4. 注册小程序后，将 `project.config.json` 的 `appid` 替换为真实 AppID，选“无云服务”即可运行当前静态展示版。
5. 本项目无第三方 npm 依赖，不需要构建 npm。

AppID 是项目标识。不要把 AppSecret、管理员凭证或上传私钥提交到仓库；当前程序不需要这些秘密信息。

## 从初版到正式发布

1. 在微信公众平台注册店铺的小程序账号，按实际主体与服务内容选择类别。若店铺有营业执照，建议按真实店铺主体办理，具体要求以平台后台为准。
2. 完成平台要求的主体验证、认证及小程序备案，取得 AppID。
3. 导入项目，在开发者工具与真机中检查五个页面、照片、分类、颜色切换、分享给朋友和朋友圈入口。
4. 核对服装名称、同款颜色归组、成分、尺码和价格；需要公开的联系信息和店铺地址可后续填写，初版没有编造这些内容。
5. 上传开发版本，设置体验成员进行验收，再按平台流程提交审核、发布。
6. 正式发布后，在平台生成小程序码。分享到朋友圈遵循微信单页模式及场景限制，应以真机结果为准。

账号注册、实名、协议接受、审核与发布由店主在自己的平台账号完成。开发工作可以先进行；上线前不能把源码预览当作已发布的小程序。

## 数据与照片

网站根目录 `catalog.js` 是唯一内容源。修改后运行 `npm run mini:sync` 同步到 `data/catalog.js`，再重新上传小程序版本。没有后台管理系统，修改源码不会自动更新已发布小程序。

14 张照片放在 `assets/images/`，为打包生成了 750 像素宽的 JPEG 派生副本；网站原照片保持原样。初版图片与数据都随小程序打包，运行时不依赖 GitHub 图片请求、服务器或外部字体。此展示版不需要自建域名或云服务器，但不免除小程序平台的注册与发布要求。

如更换照片，在 Windows PowerShell 中运行仓库根目录下的 `scripts/package-mini-images.ps1`，随后运行 `npm run mini:check`。打包检查要求整个项目小于 2 MiB，为静态展示版留出包大小余量。

## 验证

```sh
npm run mini:sync
npm run mini:check
```

检查页面与资源完整性、代码语法、包大小、分类筛选、异常分享参数、分享颜色一致性和相册参数。模拟检查不能替代微信真机验证。
